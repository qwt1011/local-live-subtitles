# 称呼一致性实验

v0.7.0 提供默认关闭的实验开关。目标是减少当前内容里同一个明确称呼的译法漂移，不是自动理解整部作品的角色关系。

## 使用和范围

高级区开启「称呼一致性」，下次开始字幕生效。回转箭头按钮清除当前捕获会话的称呼记忆。
记忆只在内存里：视频暂停/继续保留，停止后重新开始、切换语言或捕获标签页 URL 改变会清空。
URL 不变的自定义播放器换源目前不能自动识别，可手动清除。旧服务不支持该协议时，控件禁用，先重启服务。

当前词表：日语 `お兄さん`、`お兄ちゃん`、`ご主人様`、`先輩`；英语 `dork`、`dummy`、`sweetheart`。
不同源词各记各的，不合并亲疏变化；`good boy` 等可能需要句式转换的表达，以及所有通用人称代词，都不处理。

生产路径保持原来的单次翻译和提示词不变。后处理只接受一个明确源称呼、一个可对齐中文称呼，且只改一处：

1. 首次自然译文符合上述条件时，记录它的称呼选择；无法对齐就不学。
2. 后续同源称呼出现不同的受支持中文变体时，局部换回之前的译法，不重新翻译。
3. 引述、可识别的第三人称/所有格、多个候选、重复称呼、缺少译词等情况保持原文。规则偏保守，并非完整语法解析器。

例如同一会话已记录 `お兄さん → 哥哥` 后，明确呼语 `小哥，过来。` 可以变成 `哥哥，过来。`；
`他的小哥`、`小哥还是哥哥？`、没有称呼的译文都不改。不保证第一次的自然译法符合用户偏好，可清空重学。
日志的 `detail.address_change` 保留修改前译文和替换词；`address_seconds` 记录后处理耗时，便于排查误改。

## 提示词方案被否决

`tools/bench_address_memory.py` 使用三个首次自然译文作种子、八个后续句子各跑三轮，轮换顺序。
种子中两条、后续句中一条来自已有 ASR 输出，其余明确标注为人工构造。每次清空 prompt cache，单独测翻译，非端到端直播。
约束文字采用两种自拟格式，并不代表所有术语提示模板都无效。

| 方案 | 额外耗时 p50 / p95 | 不抄提示词且含目标称呼 | 抄出提示词 |
|---|---|---|---|
| 原提示词 | 基线 | 21/24 | 0/24 |
| 短称呼约束 | 173 / 492 ms | 9/24 | 12/24 |
| 较长参考说明 | 1145 / 1819 ms | 6/24 | 18/24 |

初版只检查输出是否包含目标词，会把模型抄出的术语表误算作成功；最终指标已排除这种输出。
当前生产功能不使用上述约束。逐句结果和耗时见 `runs/address_memory/prompt_ab.json`。

## 后处理验证

`tools/bench_address_postprocess.py` 的 14 个构造边界样例全部符合预期，其中 4 个修正称呼、10 个不作修改。
循环 14,000 次，后处理本身 p50 0.0076ms、p95 0.0129ms，不增加模型调用。
这些微基准数字不等于完整字幕链路的延迟；本轮未重新运行长时间音频推流 A/B。

另外离线回放本机 20 份真实会话的 1,168 条译文，实际修正次数为 0。只能说明本样本没有命中可修正的漂移，
不能声称已证明真实收益，也不能据此证明没有误改风险。因此保留实验、默认关闭，不扩大规则来追求命中数。
公开结果只包含真实会话的汇总计数，没有上传会话原文或路径。微基准结果见 `runs/address_memory/postprocess.json`。

验证覆盖会话独立性、清除后的旧队列/在途结果隔离、关闭时逐字保留原译文、一次定稿只调用模型一次、
真实 WebSocket handler 的选项和清除确认。浏览器检查覆盖开关存储、清除消息、旧服务禁用态，以及浅色/深色/320px 浮窗布局。

## 复现

```powershell
python tools/bench_address_memory.py                         # 需要本机 Hy-MT2 模型，重新测提示词 A/B
python tools/bench_address_memory.py --reanalyze             # 只重新计算结果指标
python tools/bench_address_postprocess.py                    # 无模型微基准和边界样例
python tools/bench_address_postprocess.py --sessions runs/live # 可选：只输出本机会话汇总
python -m unittest discover -s tests -p "test_*.py"
node tests/test_address_navigation.js
node tests/test_offscreen_session.js
```
